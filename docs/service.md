# 鱼册服务

## 数据与身份

Node.js 服务监听 `127.0.0.1:8787`，开发服务器转发同源 `/api` 请求。构建后的网页也可由同一服务提供。远端运行应通过 HTTPS 反向代理转发，数据库目录需持久化和备份。

SQLite 默认位于 `.data/pocket-fish.sqlite`。记录和压缩后的照片在同一事务中保存。服务按经过微信校验的 AppID 与 OpenID 唯一关联账号，每个请求按所属账号读取、修改鱼获。业务会话令牌仅保存哈希，有效期 30 天，可单独撤销。照片使用有期限的签名地址，分享导出是图片，不依赖登录令牌。

小程序调用 `uni.login` 获取一次性 code，提交给 `/api/auth/wechat`；服务端向微信 `code2Session` 换取身份，找到或创建对应账号，再签发业务会话。AppSecret 和微信 session_key 不返回客户端，前端传入的 OpenID、用户 ID 或会员等级不能用于登录。实现依据见 [uni.login 文档](https://uniapp.dcloud.net.cn/api/plugins/login.html)。

同一微信账号在另一设备登录会得到独立会话，鱼获、照片、会员等级和代表作保持一致。退出仅撤销当前会话，登录过期后重新微信登录即可取回鱼册。端侧只缓存可撤销的登录凭证；不再持久化用户鱼册、自动生成设备身份或自动导入未验证归属的数据。旧身份数据保留，需在核实归属后由运营处理迁移。

网页只提供界面预览，没有模拟微信登录入口。未配置微信凭证时登录返回明确错误，不降级创建匿名账号。正式会员支付仍须由服务端验签后更新等级。

## 配置

复制 `.env.example` 到 `.env`，按实际环境填写。密钥只在服务端读取，不放入以 `VITE_` 开头的变量。

- `FISH_PORT`：服务端口，默认 8787。
- `FISH_DB`：数据库路径，默认 `.data/pocket-fish.sqlite`。
- `WECHAT_APP_ID`：小程序 AppID，须与 `src/manifest.json` 的 `mp-weixin.appid` 一致。
- `WECHAT_APP_SECRET`：小程序密钥，只在服务端配置。
- `VITE_API_BASE_URL`：微信端使用的 HTTPS API 地址；同源 H5 保持为空。
- `FISH_RECOGNITION_URL`：兼容 OpenAI Chat Completions 的完整接口地址。
- `FISH_RECOGNITION_KEY`：模型凭证。
- `FISH_RECOGNITION_MODEL`：支持图像输入与 JSON 输出的模型名称。

三项识鱼配置全部存在才启用自动识鱼。上传后分析压缩图，最多返回三个图鉴内候选；用户确认后才归卡。图鉴外、无法确认或不含鱼时应返回空候选。失败可继续手动记录。单账号每小时最多发起 20 次模型请求，近期相同照片结果在服务进程内缓存，超时 25 秒，不自动重试。模型调用会产生服务商费用，需在接入时配置预算与真实样本评估。

## 管理会员

命令行管理只用于服务运营，不开放给浏览器。先从数据库 `users` 表查找目标账号的完整 ID，再执行：

```sh
npm run member -- USER_ID plus
```

等级值为 `basic`、`plus`、`collector`。管理操作仅改变指定用户的等级。小程序「我的存储额度」可刷新当前等级与剩余数量；页面没有可自行获取付费额度的开关。

额度校验与写入使用 SQLite 写事务。只有新记录占用额度，重复请求相同编号及编辑不增加数量；删除释放数量。降级后已有超额记录保留，只限制新增。

## 照片与时间

客户端在压缩前读取原图 `DateTimeOriginal`，保留照片中的当地日期、时分，不用 UTC 转换改变日期。无法读取、无效或未来拍摄时间不会自动填入。照片分享、保存前由服务端重新解码压缩并移除原始 EXIF 定位元数据。

浏览器处理 JPEG、PNG、WebP 等可解码图片；不支持的格式会提示换图。小程序相册可能移除元数据，读不到时必须手填。只有拍照入口在无 EXIF 时使用本次拍照时间。

## 验证范围

自动化测试使用隔离的微信接口响应测试替身，覆盖同一身份重新登录、账号隔离、会话过期与撤销、伪造身份拒绝、旧数据保留、三档额度、并发临界写入、不同微信账号隔离、重启持久化、照片签名、EXIF 去除、拍摄时间提取、缺失元数据、别名搜索和纪录计算。

浏览器上传验证使用 `tests/fixtures` 的合成图片，验证文件、日期、鱼卡与分享结果之间的对应关系，不代表真实鱼种识别准确率。真实微信登录、模型、支付以及手机相机仍需要对应服务配置和真机验证；接口测试不代表已经完成真实微信联调。
