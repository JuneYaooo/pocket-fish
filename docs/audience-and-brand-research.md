# 口袋鱼获：人群与品牌研究

研究日期：2026-10-27。目标是为「钓获照片 → 鱼种收藏 → 鱼获分享卡」选择首批用户和视觉方向。

## 证据边界

本轮为公开资料研究和品牌视觉观察，没有开展一手用户访谈或偏好测试。购买行为、被访者陈述、品牌自己的定位分别记录；品牌销量不等于用户喜欢它的界面风格。没有找到可代表全国钓鱼人群的品牌审美偏好调查。

## 人群划分

| 人群 | 有证据支持的行为或动机 | 对口袋鱼获的价值假设 |
| --- | --- | --- |
| 小物钓、鱼种收集玩家 | 以发现鱼种、拍照、解锁图鉴为乐趣；关注钓具外观与便携 | 第一优先。照片和物种收藏已存在，数字鱼册能承接原有习惯 |
| 路亚及技术进阶玩家 | 关注钓法、装备与鱼获表现；记录有助复盘 | 第二优先。个人最佳、尺寸、钓法和分享卡有价值 |
| 传统野钓、台钓玩家 | 学习技巧、看鱼情、晒鱼获；实用与性价比重要 | 保持大字、清晰数据和低成本录入；不将所有功能改成游戏 |
| 偶尔休闲、亲子参与者 | 低门槛入门、户外陪伴与拍照体验 | 容许不称重、不知道鱼种，也能先保存 |

年龄、性别不直接决定风格。国家体育总局转引的协会数据称，25—45 岁约占钓鱼爱好者的一半，但统计口径和采样细节未在报道中展开；这只能支持中青年不可忽略，不能替代产品画像。[来源](https://www.sport.gov.cn/n20001280/n20001265/n20067706/c29276616/content.html)

## 品牌与设计线索

| 品牌或产品 | 观察与证据 | 采用的设计原则 |
| --- | --- | --- |
| 响猫、子非鱼 | 《青年报》的小物钓采访提到这两个品牌，并记录猫头鱼竿、彩色浮漂、徽章等装备偏好。响猫官方展会照片可见亮黄色、奶白色、木质细节和个性化改造 | 亲近、轻松、有收藏乐趣；通过卡面和章印表达个性，不要求专业知识才能开始 |
| 小树家 | 《厦门晚报》采访记录品牌以轻量套盒、古厝红等设计切入，用户反馈适合拍照 | 将色彩集中用于收藏卡；分享卡单独设计，值得保存和转发 |
| YGC | 《天下网商》采访呈现偏技术、精致装备的路线，销售数字来自品牌自述 | 漂亮与实用可以并存；尺寸、编号、日期应清楚可靠 |
| 天元、化氏、一味、汉鼎、光威 | 《中国经济周刊》报道涉及竞技钓手背书、价格竞争和实际销售反馈 | 尊重钓友对结果与专业性的重视；不虚构稀有度，不把大鱼的成绩藏起来 |
| DAIWA PIER39 | 官方定位连接城市与自然；2026 系列与实际页面表现为功能性、克制排版、户外服饰语言。这是审美参照，不是普通钓友品牌偏好的代表性证据 | 克制排版、装备标签般的信息组织；不照搬品牌标识或服装广告 |
| Fishbrain | 官方日志产品提供鱼种清单、个人最佳、钓法/装备记录及位置隐私设置 | 同时保留鱼种层和单次鱼获层；分享表现与真实记录对应，钓点默认隐藏 |

## 本版设计

主方向为「私人鱼获藏品册」。炭黑 `#191A1C`、象牙白 `#F5F0E6` 和香槟金 `#D4BA8B` 构成基础；熔岩橙 `#ED824F`、钴蓝 `#4C69E8`、琥珀色 `#DCAE52` 集中用于卡面。具体配色属于产品视觉探索，尚未经过目标用户偏好测试。

- 鱼册：收藏编号、进度与清晰尺寸构成主体，首获与个人最佳明确标注。
- 珍藏鱼获：橙色图像区域配象牙白信息区；照片优先，没有照片时显示明确标注的图鉴插画。
- 鱼种卡：用不同色块区分已点亮物种，未解锁物种保持暗灰。颜色不代表虚构稀有度。
- 鱼获详情：深色藏品框、香槟金数据与物种色卡面；测量值注明自报，未测量保持为空。
- 分享卡：「钴蓝图鉴」以象牙白和钴蓝表现图鉴收藏；「曜石典藏」以炭黑和橙色表现鱼获纪念。切换只改变表现，不改变鱼获信息。
- 出钓：钴蓝统计区和按日期分组的记录；我的：金色、蓝色、橙色成就徽章。
- 记录：深色表单保持清晰边界和暖金选中状态；小物钓、未知鱼种、可选尺寸和草稿继续承接轻量场景。

这版仍只有四种示例鱼种。若验证小物钓用户需求，下一步应先核对当地常见小型鱼的物种与别名，再扩充图鉴；现有生成插画不承担物种鉴定功能。

## 验证方式

邀请小物钓/收集型、路亚/纪录型、传统野钓用户各 4 人做探索性访谈。让每人提供最近一次实际鱼获照片，完成记录和分享，而非只问「哪个漂亮」。观察首次记录是否顺畅、是否愿意保存或转发卡片、下一次出钓后是否回来；小样本结果用于调整方向，不推算全国偏好。
