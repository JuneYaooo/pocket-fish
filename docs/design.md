# 口袋鱼获设计

口袋鱼获把每次钓获转成个人收藏。鱼种图鉴回答「钓到过哪些鱼」，独立鱼获卡回答「那一条有什么故事」。

## 结构与视觉

主入口为鱼册、出钓、我的。鱼册显示代表作、收藏统计与鱼种图鉴；出钓按钓获日期汇集记录；我的展示成就和个人纪录。

炭黑背景、暖象牙白、香槟金细节构成私人藏品册的视觉。橙色代表卡、钴蓝与琥珀色物种卡带来收集的愉悦；编号、清晰尺寸与写实鱼类插画构成卡片语言，上传照片优先于图鉴插画。首获和纪录来自实际记录，没有随机稀有度。尺寸由用户自报，未填写时保留为空。设计依据与证据边界见[人群与品牌研究](audience-and-brand-research.md)。

卡册是物种层，鱼获是事件层；重复鱼种不重复计算图鉴，但保留每次记录。补录、修改、删除后，按钓获日期重新计算成就。同日记录用创建时间和 ID 保持稳定排序。重量与长度分别比较，只有存在更早的有效尺寸时才认定刷新纪录。

## 关键流程

拍照或导入旧照片 → 搜索鱼名确认鱼卡（配置识鱼服务后可先给出候选）→ 读取并确认钓获时间 → 可选填写尺寸和备注 → 收进鱼册 → 回看或生成含上传照片的分享图。

微信登录后开始记录，已保存的照片、鱼获、代表作与会员等级归属微信账号；重新登录同一账号继续使用同一本鱼册。未提交内容只在当前编辑会话中保留。会员按独立鱼获条数限制额度，编辑不增加条数，删除释放名额。允许不带照片先记文字。未知鱼种可以先保存待确认，不计入已点亮鱼种。分享提供钴蓝图鉴与曜石典藏两种卡面；公开分享前预览图片，城市默认隐藏，用户可主动包含城市。

## 后续产品验证

关注首次记录完成率、用户下一次出钓后的再次记录率、分享图保存率以及识别纠正需求。增加鱼种时需要先核对常用名、地方别名和物种资料。微信登录需要配置 AppID、AppSecret 与 HTTPS 服务并完成真机验证；支付尚未接入；识别服务不可用时仍可手动搜索鱼卡。
